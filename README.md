# 💧 Uncen Fresh POS
### Aplikasi Kasir & Manajemen Penjualan Air Minum Uncen Fresh

Solusi Digital Terintegrasi untuk Pengelolaan Penjualan, Stok, dan Keuangan Uncen Fresh

**Uncen Fresh POS** merupakan aplikasi kasir (Point of Sale) yang dikembangkan oleh U2PA Fakultas Ekonomi dan Bisnis Universitas Cenderawasih untuk mendukung digitalisasi pengelolaan usaha Air Minum Dalam Kemasan (AMDK) Uncen Fresh.

Aplikasi ini membantu pengelola dalam mengelola transaksi penjualan, stok produk, distribusi, pelanggan, hingga laporan keuangan secara mudah, cepat, akurat, dan dapat digunakan tanpa koneksi internet (Offline First).

---

## ✨ Fitur Utama

### 📊 Dashboard Penjualan
Dashboard menampilkan informasi bisnis secara real-time, antara lain:
- Total Penjualan Hari Ini
- Total Transaksi
- Profit Harian
- Produk Terlaris
- Produk Hampir Habis
- Ringkasan Kas

### Menu Utama Meliputi:
- 💧 Produk
- 📦 Stok Masuk
- 📋 Stok Opname
- 📜 Riwayat Stok
- ⚠ Monitoring Expired
- 🏷 Kategori Produk
- 📏 Satuan
- 🧮 Kalkulator
- 💰 Cek Harga
- 👥 Pelanggan
- 🚚 Supplier
- 🛒 Mesin Kasir (POS)

---

### 🛒 Mesin Kasir (POS)
Dirancang agar proses pelayanan pelanggan menjadi lebih cepat.
- Scan / pilih produk
- Keranjang belanja interaktif
- Edit jumlah produk
- Diskon transaksi
- Catatan penjualan
- Edit harga khusus
- Tombol nominal pembayaran cepat
- Perhitungan kembalian otomatis
- Cetak Struk
- Share Struk ke WhatsApp

### 📦 Manajemen Produk
Mengelola seluruh produk Uncen Fresh seperti:
- Air Mineral Gelas 220 ml
- Botol 330 ml
- Botol 600 ml
- Botol 1500 ml
- Galon Uncen Fresh

Setiap produk memiliki data:
- Harga Modal
- Harga Jual
- Barcode
- Kategori
- Supplier
- Minimum Stok
- Tanggal Expired

### 📈 Manajemen Persediaan
Fitur inventori meliputi:
- Restock Produk
- Stock Adjustment
- Stock Opname
- Riwayat Mutasi Barang
- Monitoring Produk Expired
- Peringatan Stok Menipis

### 🚚 Supplier
Mengelola data pemasok:
- Nama Supplier
- Nomor WhatsApp
- Alamat
- Produk yang dipasok
*Tersedia tombol Chat WhatsApp langsung dari aplikasi.*

### 👥 Pelanggan
Menyimpan data pelanggan seperti:
- Nama
- Nomor HP
- Riwayat Pembelian
- Piutang
- Total Belanja

### 💳 Piutang Penjualan (Kasbon)
Mencatat transaksi kredit pelanggan.
- Riwayat Kasbon
- Cicilan
- Sisa Piutang
- Pelunasan
- Kirim Tagihan melalui WhatsApp

### 💰 Pengeluaran Operasional (Beban)
Mencatat biaya operasional seperti:
- Pembelian Perlengkapan
- Transportasi / BBM
- Listrik / Air
- Perawatan Mesin
- Administrasi & Lain-lain
*Semua transaksi otomatis masuk ke laporan laba rugi.*

### 📊 Laporan Keuangan
Laporan yang tersedia:
- **📈 Penjualan**: Penjualan Harian, Mingguan, Bulanan, Tahunan.
- **💵 Laba Rugi**: Pendapatan, HPP, Laba Kotor, Beban, Laba Bersih.
- **📊 Neraca**: Kas, Persediaan, Piutang, Modal, Laba Ditahan.
- **💸 Arus Kas**: Kas Masuk, Kas Keluar, Saldo Akhir.

### 📷 Ekspor Data
Data dapat dibagikan dalam bentuk:
- PNG (Faktur & Laporan Keuangan)
- PDF (Print layout)
- JSON Backup
*Laporan dapat langsung dikirim melalui WhatsApp, Telegram, atau Email.*

### 🔒 Keamanan & Utilitas
- Login Username
- PIN Keamanan
- Backup Database
- Restore Database
- Reset Database
- Penyimpanan Lokal Offline

---

## 📱 Teknologi
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Android**: Kotlin, Android SDK, WebView, SharedPreferences, FileProvider
- **Database**: Local JSON Database (Offline First)
